# Книжный круг — GitHub Pages

Готовая статическая страница проекта буккроссинга. Для публикации:

1. Создайте публичный GitHub-репозиторий, например `knizhny-krug`.
2. Загрузите в корень репозитория три файла: `index.html`, `style.css`, `script.js`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Подождите публикацию и откройте адрес, который GitHub покажет в настройках Pages.

Страница не требует регистрации, базы данных, сбора данных посетителей или отдельного сервера. Аккордеон правил работает на JavaScript. Для смены названия, текстов или адреса достаточно отредактировать `index.html`; цвета и оформление находятся в `style.css`.

Перед публикацией при желании добавьте точное название проекта, адрес полки и контакты организаторов. Сейчас сайт не указывает адрес или контакты, чтобы не публиковать неподтверждённые данные.
